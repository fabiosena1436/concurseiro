Ótimo! Instalei a biblioteca do Google Gemini AI.

Para gerar questões dinamicamente, vou precisar de uma chave de API do Google AI Studio.

**Por favor, siga estes passos:**
1.  Acesse o [Google AI Studio](https://aistudio.google.com/app/apikey).
2.  Crie uma nova chave de API (ou copie uma existente).
3.  Abra o seu arquivo `.env` e adicione a seguinte linha, substituindo `"SUA_CHAVE_AQUI"` pela chave que você copiou:
    ```
    VITE_GEMINI_API_KEY="SUA_CHAVE_AQUI"
    ```
